## 视觉约束

- 背景 #FCF8F2，正文 #243D35，主色 #285848，浅绿容器 #E1F1E4。
- 首页采用纵向通知列表，不做四个同等面积的彩色大方格。
- 分类必须包含文本标识，不只依赖颜色。
- 原生系统字体；实际 Android 实现采用 sp、系统字体缩放和最小 48dp 触控目标。
- 三个入口：收件箱、已收起、设置。
- 0.3 首页展示「现在看」「稍后看」「待确认」三个可见分组；明确营销或用户偏好收起的消息放到「已收起」。四象限不再作为每日手工整理任务。
- 每条通知显示决定原因；数量从实际本机记录计算，不将演示内容混入统计。
- 暖白主题已用于 MVP，深色主题沿用相同语义色关系。

## MVP 功能边界

授权后监听用户选定应用的文字通知，先本机保存，再用本地规则自动整理。用户可配置 Chat Completions 兼容 HTTPS 服务或 Jev 官方判断服务，并单独允许来源发送给云端；默认关闭上传。新手流程无需填写 API 密钥也能体验。

常见验证码保持本机，规则拿不准、云端不可用和低置信度结果保留可见。卡片提供单条纠正、星标及恢复；「这类以后少显示」只影响指定应用的指定类型，可在设置撤销。关注词本地按词匹配，云端用于相关性判断，不代表已经实现兴趣内容推荐流。

本版不改变原系统通知，不追加系统提醒、响铃或定时摘要。标题「现在看」表达收件箱优先级，不承诺拦截原通知或系统即时提醒。

## 0.3 自动整理交互

首页的第一任务是让用户看懂已经整理好的结果。主操作为「这条很重要」「稍后看」「这条收起来」和恢复，而非要求每条通知填写重要性与紧急性。分类理由用短句呈现；用户仍可查看正文和来源。

「待确认」承接分析中与不确定内容，不用动画、红点或倒计时强迫用户立刻处理。用户纠正当前这一条，与保存此应用此类型的长期偏好分开。当前内容被纠正后不被迟到分析覆盖；来源修改正文后重新分析并保留关注。

新手引导在页面与操作位置说明下一步：选择来源、授权、查看营销与交易异常两条离线示例的不同归位，再体验一次收起与恢复。用户看到的是自动整理的效果及如何纠正，而非手工分类教程。示例明确标注，不上传且不写入真实通知库。

智能整理设置分别展示：关注内容、服务配置、允许云端的应用、云端开关、固定虚构示例连接测试、收起偏好撤销和重新整理。保存按钮使配置变更明确生效；提示云端可能处理允许来源的已保存与后续通知。不开启云端也保留完整本地使用流程。

## 0.4 隐私与判断服务

沿用现有暖白、墨绿和小耳角色。隐私是独立设置入口，不借角色形象暗示“绝对保密”。默认遮住正文、应用名称与判断理由；系统凭据验证后显示最多 120 秒，进入后台或熄屏后重新遮住。开启来源、查看 AI 配置和修改隐私设置均需先解锁。未设置设备锁时，明确指导用户先去系统设置。

「仅本机」与「允许云端」分开，前者优先。默认微信、QQ 与常见短信应用仅本机处理，云端总开关仍默认关闭。默认锁屏暂停上传；已有请求无法撤回。基础脱敏不代表匿名，Jev 仍是云端服务，界面不把它描述为本地模型或已证明更私密。

消息内容字段加密保存，但包名、通知 key、时间和分类等元数据仍为明文。历史保留可选不自动清理、7 天、30 天，清空历史保留来源设置和偏好。由于可能影响已有数据，删除使用确认对话框；日常新手教学仍使用页面内指引。

Jev 和兼容接口共享最终可见性策略，模型不能自行获得上传权限。格式错误、低确定性、含混用途、注入指令和疑似截断的通知保留可见。40 条虚构中文案例用于工程回归，不宣传为真实准确率。尚无真实 API 与真机端到端结论。

## 0.4.1 信息层级与阅读负担

首屏只回答「现在值得看什么」和「下一步做什么」。通知标题、来源和时间构成主要扫描路径；正文、判断依据、技术状态与次要操作按需展开。不要在同一张卡片同时重复分类标题、分类描述、状态说明和模型解释。每个区域保留一个明确主动作，低频纠正操作进入更多菜单。

设置首页只呈现入口和简短当前状态。服务连接、来源授权、存储期限等细节在对应页面展开，长说明移到帮助或详情；必要披露仍要在授权控件附近可见，不能为了精简隐藏「将向云端发送什么」「仅本机优先」「已经发出的请求无法撤回」。精简的是重复解释，不是知情选择。

内容默认遮蔽时，用页面级提示说明一次解锁操作，卡片保持低信息密度；不在每条通知里重复一段安全说明。新手引导贴近当前操作，一次只引导一个动作。界面主层优先使用用户语言，不堆服务协议、测试数字与实现术语。

浏览器预览改为「收件箱 / 智能整理 / 隐私」三个页签，每次仅展示两张核心截图与短标题。图片占主要视觉面积，固定可滚动视窗，点击可打开完整原图。Robolectric 非真机、真实 API 尚未验证的说明保持可见；详细隐私和能力边界默认折叠。暖白背景、墨绿文字、柔和容器与留白延续原方向，不引入新的装饰图形或外部资源。

## 0.4.2 设置按日常任务收拢

设置首页只保留两个主要入口：「整理哪些应用」和「隐私保护」。普通用户从自己的问题出发进入，不需要先理解来源、允许云端、模型服务和 API 的关系。首页可保留简短当前状态，不展开应用列表、权限步骤、服务表单或成段说明。

「整理哪些应用」子页负责应用选择与通知访问授权，操作提示放在对应控件旁边。收纳来源的选择不等于授权上传云端；两者的权限关系和已有保护逻辑保持清楚，不能因界面收拢自动扩大授权范围。

API、Jev、密钥、模型等配置放到低频的「高级设置」入口，进入后再展示原有服务配置。不开启云端即可完成基础使用。重学引导保留为辅助操作，带用户回到真实页面完成动作，不要求用户先阅读功能介绍。

浏览器预览相应改为「收件箱 / 简单设置 / 隐私」三个页签。设置组展示精简首页和应用选择子页；服务配置截图只在展开详情中提供链接。主视觉应让用户看到日常整理效果、知道从哪里开始设置，而非列出系统拥有多少功能。

- https://github.com/airbnb/lottie-android ：已评估。目前素材为 PNG，没有对应的动画 JSON，因此没有引入 Lottie 依赖或下载他人角色动画。

具体实现为原创 Compose 组件，无复制上述仓库源码。启动图形入场 480ms，淡出 220ms；点按可跳过，关闭系统动画时不等待。页面切换 220–260ms；星标轻弹；来源选中变色；通知列表插入、移除、移动动画；正文展开使用尺寸过渡。角色点按轻晃一次，不持续循环。

引导使用控件附近的短提示与描边；0.3 内容已改为自动整理及纠正示例。跨页面时突出底部导航，由用户切换。支持跳过、继续与重学，不向 Room 写入示例。当前为嵌入式提示，没有全屏遮罩。

浅色空状态使用完整倾听原图（保留原图背景和来源标记），深色空状态使用用户提供的深色头像，避免浅底图片块。桌面图标使用用户提供的头像资源，启动器裁切与主题图标行为仍待真机验证。

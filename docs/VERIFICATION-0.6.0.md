# 轻序 0.6.0 验证记录

日期：2026-10-15

本版针对重复处理造成的开销、AI 开启后的反馈不足，以及用对话整理通知的需求。

## 本次变更

- **减少重复工作。** 相同通知快照不再重写数据库或安排重复分析；收件箱订阅内复用未变化字段的解密结果。默认关闭的通知栏功能不读消息库，数量摘要不解密正文；偏好重整只更新理由密文。初始化和加解密明确在 IO 执行，应用列表短时缓存，收件箱筛选及分组按依赖缓存。
- **显示实际处理状态。** 首页区分本机规则、未配置、无授权来源、隐私暂停、正在请求、失败和已完成的 AI 整理。启用开关不等于模型正在处理，只有结果被数据库接受后才记录成功。
- **小耳助手。** 首页进入对话，支持 Chat Completions 与 Claude Messages。读取最新 80 条符合来源选择的未处理候选，过滤隐私和敏感限制后最多发送 20 条，连同本次提问和最多 6 条近期上下文。Jev 继续用于自动判断，不能作为聊天协议。
- **确认与撤销。** 模型只能返回文字和有限动作建议；优先看、稍后看、收起促销、已处理均先展示具体消息，再由用户确认。隐藏仍通过本机保护规则。数据库在同一事务内比较完整旧状态，只改状态字段；跳过后来变化的消息，撤销也只恢复实际成功且未再变化的行。
- **会话隐私。** 对话、草稿和撤销暂存仅在内存；后台、锁回或授权变化会清除。请求写入前复查授权和消息内容；新增消息改变临时编号时不再发送旧对话上下文。支持停止进行中的对话，已经发出的数据不能撤回。

## 验证边界

未连接 Android 真机或真实服务密钥。性能测试验证减少了重复解密、写入和查询，不是帧率、耗电或长时间后台稳定性的测量；不能宣称已彻底消除卡顿。真实 API 兼容性、中文判断质量、手机网络、系统凭据流程、覆盖安装和持续接收仍需在目标手机验证。

本机处理是规则，端侧模型尚未接入。仅本机来源优先于云端授权；基础脱敏不是匿名化。聊天只分析最近有限范围的通知，不是完整消息检索，也不能读取 Android 未提供的正文。原通知仍先由系统发布，轻序不能保证在第一次响铃或振动之前拦截。
